# 天帝教社群交流規範（公開社群範本）

**適用範圍：** 天帝教相關的公開 Facebook 粉絲專頁、公開社團、Instagram、Threads、YouTube 頻道等任何人都可以瀏覽或留言的社群，可依各社群性質調整使用。

## 一、歡迎你來到這裡

這裡是天帝教與各界朋友交流的園地。無論你是不是天帝教同奮、有沒有宗教信仰，都歡迎你來看看、留言、提問與分享。

天帝教的教誨提醒我們：「宗教之結合在道、在義」；人與人相交，應以真誠相待，不為謀私、謀利。我們也期許自己在網路上的每一次發言，都能做到：

**言語溫和、態度誠懇、行為謙虛。**

我們歡迎不同的觀點，也願意傾聽對天帝教的批評與建議。願大家以溝通增進理解，以尊重化解歧見，一起維護友善、安心的交流環境。

## 二、我們期待的交流方式

1. **彼此尊重：** 尊重不同的意見、信仰與生活方式，以對事不對人的方式討論。
2. **善意交流：** 以溫和、誠懇的方式表達意見，願意傾聽並理解他人。
3. **心平氣和：** 網路文字容易引起誤會。天帝教的教誨勉勵我們「生氣時不做決定、不做判斷，心平氣和才是正道」。遇到不同意見時，先停一停，再回應。
4. **尊重事實：** 留意資訊來源，對尚未確認的消息保持審慎，不任意轉傳，也不做出未經查證的指控。
5. **尊重隱私：** 公開社群的留言，所有人都看得到，請不要留下自己或他人的電話、地址、身分證字號等資料。分享照片、對話截圖或其他涉及他人的內容前，也先想想當事人是否願意；即使資料已經出現在其他地方，也不代表可以再轉傳。
6. **共同維護社群：** 看到不當言論或可疑資訊時，歡迎私訊管理員，避免在留言區對罵或擴大爭議。

## 三、不適合出現在這裡的內容

為了讓大家安心交流，請避免下列行為。排序大致依嚴重程度：前幾項可能觸法或侵害他人權益；後幾項即使合法，也不適合出現在本社群。

1. **詐騙與違法吸金：** 以不實說法騙取財物，或以高額報酬、拉人頭等方式吸收資金。
2. **毀謗與恐嚇：** 散布不實指控、損害他人名譽，或以言語威脅他人。
3. **侵害隱私與肖像：** 未經同意，公開或轉傳他人的個人資料、私人對話、照片或影像。
4. **冒用他人身分：** 假冒他人、天帝教單位或教內人士發言。
5. **侵害著作權：** 未經授權，轉載他人的文章、圖片、影音等作品。
6. **人身攻擊與騷擾：** 謾罵、嘲諷、貶損人格，持續糾纏特定人士，或煽動他人圍剿。
7. **借天帝教名義背書：** 以天帝教名義或教內身分，替個人或他人的商業、投資等利益活動背書或牽線。
8. **商業廣告與業務招攬：** 為個人或商業利益，張貼廣告、推銷商品、團購代購，或招攬直銷、保險、投資、借貸、募資等業務；以及從留言區私訊他人招攬。
9. **干擾正常交流：** 洗版、大量張貼與本社群無關的內容，或為政治、選舉及天帝教與輔翼組織以外的團體進行宣傳動員。

其他違反法律或平台規範的內容，也同樣不適合出現在這裡。

這些規範並不是要限制正常的意見表達。我們不會只因為意見不同就刪除留言；理性的批評與討論，都會受到尊重。

## 四、請提高警覺

本社群及天帝教的單位，**不會透過私訊向你推銷商品、招攬投資、借貸或要求匯款**。如果有人以天帝教或教內人士的名義私訊你提出這類邀約，請不要回應，並告訴管理員。

天帝教的官方社群，以天帝教官網公布的清單為準〔官網清單網址：＿＿＿＿＿＿〕。

「保證獲利」「穩賺不賠」「高額回報」這類說法，常是詐騙或違法吸金的警訊，請特別留意。

## 五、管理方式

為了維護交流品質，管理員會視情節輕重與影響程度，採取適當的處理方式：

1. 提醒或勸導。
2. 隱藏或刪除不適當的留言、貼文。
3. 暫時限制留言或發文。
4. 情節重大或屢勸不聽者，封鎖或移除參與資格。

**不必等司法認定：** 第三段前幾項內容是否違法，最終由司法認定；但在認定之前，傷害可能已經擴大。因此，只要內容有合理疑慮，管理員就可以先行隱藏或移除，並建議受影響者循適當途徑處理。這是為了保護社群，並不代表對任何人做出法律判斷。

管理員會盡量依一致、合理的原則處理，不因身分、信仰或立場而有差別對待。對處理方式有疑問，歡迎私訊管理員討論。

## 六、遇到問題怎麼辦

看到疑似違反本規範的內容，可以這樣做：

1. **保留完整紀錄：** 留下網址與發言時間，避免只截取片段而失去前後脈絡。
2. **私訊管理員或使用檢舉功能：** 交給管理員或平台處理，不必在留言區公開回應。
3. **嚴重情況另尋協助：** 涉及威脅、個資外洩或其他可能違法的情形，可報案或尋求適當協助。

## 讓我們一起維護良好的交流環境

涵靜老人教導同奮：**尊重、親愛、服務、鼓勵、寬恕。**

我們也願以同樣的心，對待每一位來到這裡的朋友，一起維護一個安心交流、彼此學習、互相鼓勵的園地。
